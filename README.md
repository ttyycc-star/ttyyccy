# 库里投篮解剖 · Shooting Lab

一个纯静态的中文单页网站：把斯蒂芬·库里的投篮拆成 **动作基础 → 发力模式 → 年龄曲线 → 数据** 四层，配一张可拖动的年龄滑杆和三张逐季数据图。

## 打开方式

双击 `index.html` 即可（不需要服务器、不需要联网、没有任何依赖）。

想用本地服务器也可以：

```powershell
cd curry-shooting
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000
```

## 内容结构

| 版块 | 讲什么 |
| --- | --- |
| 01 动作基础 | 六个可检查的零件：站姿与落地脚、Dip 下沉、一体式出手、肘与手型、出手点与弧线、跟随动作 |
| 02 发力模式 | 脚踝 → 膝 → 髋 → 核心 → 肩肘 → 腕指的动力链；下肢主导 vs 上肢定向；一体式与两段式的结构差异（可切换） |
| 03 年龄曲线 | 22–38 岁共 17 个赛季，滑杆联动真实数据 + 该阶段的动作漂移描述；下方是六个阶段的时间线 |
| 04 数据 | 三分命中率、场均三分出手、场均得分三张图，含生涯均值虚线与 2019-20 伤停标注 |
| 05 训练清单 | 把他的投篮顺序翻译成四组可执行练习 |

## 交互

- 年龄滑杆：拖动切换赛季，右侧读数（命中率 / 三分出手 / 得分 / 出场）与阶段说明同步更新
- 一体式 / 两段式切换
- 顶部导航随滚动高亮
- 支持 `?goto=mechanics` 之类的深链（`mechanics` `power` `age` `data` `drills`）

## 文件

```
index.html   结构 + 静态内联 SVG 图表
styles.css   全部样式（深色 + 勇士金），含响应式
data.js      逐季数据 + 阶段文案
app.js       滑杆、切换、导航高亮、数字滚动
```

## 数据来源与口径

- 数据：ESPN 球员逐季统计，2009-10 → 2025-26（2026-27 赛季刚开打，未纳入图表）。
- 生涯三分命中率 42.1%、生涯三分命中 4,245 记，为截至 2025-26 赛季结束的累计值。
- 2019-20 仅 5 场（左手骨折），命中率 24.5% 低于图表纵轴下限，已夹到轴底并单独标注。
- 机制描述（下肢占比、出手时间 0.3–0.4 秒等）来自公开比赛影像与投篮分析的归纳，属训练界通行说法，**不是**三维测力或运动捕捉的实验室数据。

## 说明

- 图表是静态内联 SVG，所以禁用 JavaScript 也能看到完整数据。
- 页面完全不依赖外部字体和 CDN，离线可用。
